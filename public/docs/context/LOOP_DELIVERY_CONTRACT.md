# JGC.LABS — LOOP DELIVERY CONTRACT

Un loop no se entrega como simple explicación o prompt.

Debe contener:
1. Código/estructura correspondiente al estado real.
2. Contexto actualizado.
3. Decisiones.
4. TODO.
5. CHANGELOG.
6. Especificación LOOP_XX.
7. Prompt de ejecución.
8. Validación y QA.
9. Handoff.

El ZIP representa el estado completo del proyecto después de ese loop.
