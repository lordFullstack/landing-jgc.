# CLAUDE — MOCKUP IMPLEMENTATION RULES

Before implementing UI:
1. Read `docs/reference/MOCKUP_SPEC.md`.
2. Check `docs/reference/mockup/` for the approved visual reference.
3. Treat the spec as a visual contract.
4. Do not invent visual patterns.
5. If mockup and spec conflict, report the conflict.
6. Validate at 320, 375, 390, 430, 768, 1024, 1280 and 1440px.
7. Update documentation after implementation.
